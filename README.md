# Kabati

**Your applications. One organised shelf.**

Kabati is a lightweight, customisable Linux desktop application launcher for the **Wes OS** ecosystem. Named after the Swahili word *kabati* (cupboard or cabinet), it provides a clean digital shelf for your installed apps.

## Features (v0.1.0)
- **Application Grid:** Organised grid of installed applications.
- **Application Search:** Fast filtering as you type.
- **Category Navigation:** Groups apps into logical categories.
- **Application Launching:** Cleanly launches selected apps.

## Dependencies (Debian 13 / XFCE / X11)

    sudo apt install -y python3 python3-gi gir1.2-gtk-3.0

## Installation

    git clone https://github.com/<new-username>/kabati.git
    cd kabati && chmod +x install.sh && ./install.sh
